# iPhone 真机验收

自动化测试验证了 ICS 字节、解析往返与接口行为，但 iPhone 日历的刷新周期、提醒弹出和显示效果只能真机确认。按下面的顺序逐项打勾，记录 iOS 版本与结果。

## 环境

- [ ] 服务通过有效 HTTPS 证书访问（生产域名），或在局域网调试时 `WEB_ORIGIN` 为电脑的局域网地址（仅限 HTTP 调试，iOS 可能要求 HTTPS 才能订阅）。
- [ ] 准备一个测试账号，不要用真实家人数据做破坏性测试。
- [ ] 记录：iOS 版本 ______，设备 ______，账号时区 ______。

## 添加订阅

1. 网页「订阅」→ 输入设备名「iPhone」→「创建订阅地址」→「复制 HTTPS 地址」。
2. iPhone：设置 → 日历 → 账户 → 添加账户 → 其他 → 添加已订阅的日历 → 粘贴地址 → 下一步 → 存储。
   - 或在 iPhone Safari 里打开网页，点「用日历 App 打开（webcal）」。

- [ ] 订阅成功，日历名称显示为「<显示名称>的纪念日」。
- [ ] 关闭页面再打开「订阅」，同一地址仍然完整显示，可以再次复制。

## 事件显示

为测试账号准备以下事件后，在 iPhone 日历里下拉刷新（设置 → 日历 → 账户 → 已订阅的日历 → 也可调整「获取」频率）：

| 事件                             | 期望                                                         | 结果 |
| -------------------------------- | ------------------------------------------------------------ | ---- |
| 公历生日 1990-05-20，前缀 🎂     | 每年 5/20 全天，「🎂 小明 N 岁生日」，N 与网页预览一致       | ☐    |
| 纪念日 2021-05-20                | 2026 年显示「第 5 周年」                                     | ☐    |
| 年份未知的生日                   | 每年显示「小明生日」，无数字                                 | ☐    |
| 2000-02-29 生日，规则 2 月 28 日 | 平年显示在 2/28，闰年在 2/29                                 | ☐    |
| 农历 1990 腊月廿九               | 2026-02-16 显示「35 岁」（农历 2025 年），日期与网页预览一致 | ☐    |
| 农历闰月或三十的事件             | 与网页预览的「未来 5 次」逐条一致                            | ☐    |
| 普通事件 10/1–10/7               | 一条横跨 7 天的全天事件，10/8 不显示                         | ☐    |
| 12/30 起 5 天                    | 跨年显示到 1/3                                               | ☐    |
| 名称含 emoji、逗号、分号、换行   | 显示原样文字，无乱码，无多出的事件                           | ☐    |
| 备注                             | 事件详情里显示备注                                           | ☐    |

- [ ] 所有事件显示为「空闲」（不占用忙碌时间）。

## 提醒

- [ ] 「提前 1 天 09:00」的提醒在前一天 09:00（账号时区）弹出。
- [ ] 两条提醒都生效。
- [ ] 跨天事件只在开始日前提醒一次。
- [ ] iPhone 设置 → 日历 → 已订阅的日历 →「移除提醒」关闭时提醒才会出现（iOS 默认可能移除订阅日历的提醒，需确认此开关）。

## 修改与同步

- [ ] 网页修改事件名称后，iPhone 刷新显示新标题，没有出现重复事件（UID 稳定）。
- [ ] 删除事件后，刷新后从 iPhone 消失。
- [ ] 新增事件后，刷新后出现。
- [ ] 订阅地址保持不变，不需要重新添加。

## 撤销与轮换

- [ ] 网页「轮换」后，旧订阅刷新失败或停止更新；用新地址重新添加可用。
- [ ] 网页「撤销」后，iPhone 上的订阅停止更新。
- [ ] 管理员停用该账号后，订阅停止更新。
