# 引导与演示素材

README 和帮助抽屉里的截图、演示视频都由 `scripts/captureGuideMedia.ts` 从真实界面录制，不手工绘制或修图。界面、文案或引导步骤改动影响这些画面时，重新生成并逐张核对。

## 生成

```sh
pnpm media:guide          # 中英文都生成
pnpm media:guide zh-CN    # 只生成中文
pnpm media:guide en       # 只生成英文
```

需要本机安装 Microsoft Edge（与端到端测试相同，Playwright 使用 `msedge` 通道）。每种语言约 2 分钟，结束时打印每个文件的大小。

桌面截图和录屏的视口分别为 1440 × 900 和 1280 × 800。视频为 Playwright 录制的 WebM，不转码、不做 GIF：GitHub 页面里不能内嵌播放，README 用封面图链接到视频文件。

## 隔离与清理

- 每种语言启动一个独立实例：中文 Web 4320 / API 4321，英文 Web 4330 / API 4331，只绑 `127.0.0.1`。SQLite 和日志都在 `.tmp/guide-media/<语言>/`，每次运行前清空；显式传入的环境变量优先于 `.env`，不会读写 `.env` 配置的数据库和日志目录。
- 实例以 development 模式运行，但关闭开发免登录（`DEV_AUTH_BYPASS=0`），素材走真实的首次设置、管理员建号和登录。
- 录制结束后实例自动退出。临时数据只在 `.tmp/guide-media/` 下，需要时整个删除即可；`.tmp/` 由 Git 忽略。

## 内容约定

- 人物、日期和账号全部虚构，定义在 `scripts/guide-media/mediaFixtures.ts`。展示账号的事件经应用自己的「备份」页导入，与用户导入走同一条校验；年份相对当前年份计算，隔年重新生成时岁数和周年数保持在相近范围。
- 订阅二维码含私密 token，录制时统一模糊；画面中不出现订阅地址明文。
- 标注框（琥珀色虚线）、说明标签、字幕和指针圆点是录制脚本叠加的演示层，与产品界面明显区分，不响应点击。
- 核心流程视频里「日历拉取订阅」由录制脚本代替日历 App 发起一次真实的 ICS 请求，字幕写明了这一点；没有录制任何日历客户端的界面。
- 界面文字直接取应用的语言包定位元素，文案改动后脚本不会对着旧文字找按钮；找不到元素时脚本报错退出，不生成残缺素材。

## 核对清单

重新生成后逐个打开检查：

- 画面与当前版本一致：按钮、文案、布局没有过期，没有错误提示或开发警告浮层。
- 没有真实姓名、账号、订阅地址或未模糊的二维码。
- 标题里没有未替换的模板变量、`NaN` 或负数。英文默认标题模板目前固定写 “th”（21、22、23 等会显示成 “21th”），示例年龄因此避开 1、2、3 结尾。
- 视频从头到尾流程完整，字幕与画面对应；文件大小与上次相近（截图约 50–100 KB，视频约 2–3 MB）。
